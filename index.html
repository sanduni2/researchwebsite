Key Features

Farm Intelligence Workflow

Each module is designed as part of one farm loop: detect, predict, optimize, verify.

01 / Detect

Poultry Health Monitoring

MFCC + CNN audio screening, visual confirmation, and droppings-based disease classification.

02 / Predict

Environment Intelligence

Tracks temperature, humidity, ammonia, light, and noise with predictive egg production analytics.

03 / Optimize

Feed and Growth Optimizer

ResNet50 feed-level recognition and Random Forest growth prediction for dynamic feed planning.

04 / Verify

Egg Grading and Traceability

AI grading, defect detection, and tamper-proof Polygon blockchain records with QR verification.

Sensor Layer Audio + Image + Environmental + Feed + Egg Data
Inference Layer CNN, MobileNetV2, ResNet50, Random Forest
Action Layer Alerts, Feed Plans, Quality Flags, Manager Notifications

Technology Stack

Built for Real Farm Deployment

Field Hardware

Raspberry Pi 4, Jetson Nano, ESP32, MEMS microphones, cameras, and distributed IoT sensors.

Model Intelligence

CNN, MobileNetV2, ResNet50, Random Forest regressors/classifiers, and transfer learning workflows.

Platform Core

Flask REST API, MongoDB centralized storage, React Native/Web interfaces, and Polygon blockchain.
